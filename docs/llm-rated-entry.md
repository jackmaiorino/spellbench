There are no inference retries, fallback choices or model substitutions. `python/tools/xmage_verified_entry.py` verifies the fixed build manifest and every jar, then copies the source database into a private process directory before starting Java. Engine source and rules are unchanged.

The benchmark command requires that ledger's policy to match 4,096 requests, ten million reported tokens, two hours and at most four concurrent requests.
