The initial definition is `benchmarks/standard-mirror-xmage/benchmark.json`: two fixed 60-card catalogue decks, random, heuristic and Luna, four seat-swapped pairs per deck and matchup. That is 48 games, including 32 Luna games. The published rating must include its paired bootstrap interval and the restricted deck-pool description. Results do not select a different model, prompt or easier deck pool. Wins, losses, forfeits, caps and halts retain the arena's existing treatment.

Luna is fixed to `gpt-6-luna`, low reasoning, prompt `spellbench-llm/v1`, one-decision history, no card-text supplement, 1,024 reported output tokens, 256 requests and 750,000 reported tokens per game. Its child uses the exact image already verified in the engineering pilot; the Windows import mapping and recoverable archive are in `llm-magic-pilot.md`. The host owns inference and account renewal, and the child has no provider credentials or network. The arena labels the trusted broker self-reported; this lane grants no new sandbox admission.

`python/tools/llm_hosted_bot.py` supplies a normal agent command to the arena. Hello preflight reads no credentials and makes no model request. The explicit `--renew-profile-before-game` option renews the existing app grant before game_start, under the profile's cross-process lock. There are no inference retries, fallback choices or model substitutions. `python/tools/xmage_verified_entry.py` verifies the fixed build manifest and every jar, then copies the source database into a private process directory before starting Java. Engine source and rules are unchanged.

All games and qualification calls share a host-only SQLite ledger. The benchmark command requires that ledger's policy to match 4,096 requests, ten million reported tokens, two hours and at most four concurrent requests. Reservations include pending work; failed requests stop later admission across workers, and abandoned reservations remain unknown usage. Reported output and token limits apply after response completion, so they are not a hard provider allowance cap. A new budget cannot replace an existing one.
