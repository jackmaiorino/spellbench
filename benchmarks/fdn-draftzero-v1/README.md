# DraftZero Exp1 FDN mirrors

The full round robin contains public gen0, gen10 and gen33 checkpoints plus uniform and heuristic anchors: 1,280 games, sixteen public FDN decks, four seat-swapped pairs per deck and matchup. Each matchup has 64 complete pairs; each entrant has 512 scheduled games. Ratings are comparable only within this benchmark's engine, decks and clock. Deck attribution and lists follow `fdn-mirror-v0` and the XMage FDN catalog.

All checkpoints use the published final-evaluation `published-exp1-final-eval-fair-v1` settings, including 96 visits and the source's 12-second clock after a legal future. These are named fair variants: permitted hidden-world reconstruction, own-visible replay and disabled opponent-hand encoding change the source evaluation. Confined CPU float32 inference differs from the released float16 run. The adapter owns checkpoint loading inside its pinned Docker image; checkpoint pickles are never loaded in the host process. Gen0 remains explicitly present as the released initialization checkpoint; it is not evidence of learning.

The definition pins each checkpoint through `checkpoint`, the mounted inference model source, feature vocabulary and action vocabulary, every engine jar, all 309 model classes, two model resources, the Commons Math dependency and adapter inputs through `evaluation_inputs`, plus the reviewed engine/model manifests, Java executable and confined image. Runtime versions bind the checkpoint, build and profile hashes. `engines/xmage/releases.json` supplies the exact upstream source and asset hashes. No weights or compiled binaries are checked into this directory.

Runtime placeholders are resolved from the environment or ignored `benchmarks/local.json`: `PYTHON`, `JAVA`, `XMAGE_VERIFIED_ENTRY`, `XMAGE_NEURAL_RUNTIME`, `XMAGE_BUILD`, `XMAGE_BUILD_MANIFEST`, `XMAGE_MODEL_BUILD`, `XMAGE_MODEL_SOURCE` (the Python tools directory), `XMAGE_RELEASES_MANIFEST`, `XMAGE_PUBLISHED_PROFILE`, `XMAGE_SEARCH_MATH`, `XMAGE_CHECKPOINT_ROOT`, `XMAGE_DB`, `XMAGE_ENGINE_WORK` and `XMAGE_AGENT_WORK`. Model manifest dependencies must retain their declared paths. This version uses the reviewed Windows/JDK23 engine and the integrated model build; a different build or checkpoint identity needs a reviewed definition and new public commitment before rating.
