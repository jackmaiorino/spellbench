# DraftZero GNN FDN mirrors

The full round robin contains DraftZero's FDN graph network and uniform and heuristic anchors: 384 games, sixteen public FDN decks, four seat-swapped pairs per deck and matchup. Each matchup has 64 complete pairs; each entrant has 256 scheduled games. Ratings are comparable only within this benchmark's engine, decks and clock. Deck attribution and lists follow `fdn-mirror-v0` and the XMage FDN catalog.

`draftzero-fdn-gnn-100-fair` is DraftZero's FDN graph network (`danbrooks/draftzero-fdn-gnn@a8351e8b`, weights CC BY 4.0) with its released PIMC tree search at 100 simulations a decision. It is a fair variant: one permitted sampled world with the opponent's hand hidden, confined CPU float32 inference, and the kit's declining answer where a world cannot be searched or a callback replayed. It runs on its own model build (the graph stage beside MageZero v0.2) next to this board's engine overlay; its pinned image is built from `integrations/xmage-models` with `--target gnn`. Docker image ids are not reproducible, so the run host loads that exact image (`docker save`/`docker load` keeps its id). Evidence: `engines/xmage/models/evidence/2026-10-09-draftzero-gnn-goldens.md`.

The definition pins the model build (`--model-build-sha256`, every class and resource file through `evaluation_inputs`), the engine overlay, every engine jar, the Commons Math dependency, the Java executable, the card database and the confined image. The runtime version binds the build and profile hashes. `engines/xmage/releases.json` supplies the exact upstream source and asset hashes. No weights or compiled binaries are checked into this directory.

Runtime placeholders are resolved from the environment or ignored `benchmarks/local.json`: `PYTHON`, `JAVA`, `XMAGE_VERIFIED_ENTRY`, `XMAGE_BUILD`, `XMAGE_BUILD_MANIFEST`, `XMAGE_MODEL_BUILD`, `XMAGE_SEARCH_MATH`, `XMAGE_DB`, `XMAGE_ENGINE_WORK`, `XMAGE_AGENT_WORK`, `XMAGE_GNN_RUNTIME` (`python/tools/xmage_gnn_runtime.py`), `XMAGE_GNN_SOURCE` (that tools directory), `XMAGE_GNN_MODEL_BUILD`, `XMAGE_GNN_MANIFEST` (the `engines/xmage/releases.json` it was built with) and `XMAGE_GNN_ROOT` (the release inputs). A relocated Commons Math jar must match the build manifest's declared SHA256. A different build identity needs a reviewed definition and a new public commitment before rating.

Throughput qualification uses scheduled games 0 (uniform/heuristic), 128 (uniform/GNN), 257 and 258 (heuristic/GNN, the GNN in both seats on two decks). Serial and parallel trials use the same games and secret and select by completed wall time; this sample changes no rated game.
